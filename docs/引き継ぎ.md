## 4. 作業の手引き

### 始める前
```bash
cd /Users/gorite/Developer/cycle_map
git pull
```
`CLAUDE.md` と `AGENTS.md` が基本ルール。`Archives/` は触らない。`data/`・`work/`・`venv/` は動かさない。

### 実機検証 (Mac)
- debug ビルド: `cd application && ./gradlew :app:assembleDebug -Pcyclemap.appIdSuffix=.mac` (パッケージは `com.gorite.cyclemap.test.mac`)。
- 回帰: `CYCLEMAP_PACKAGE_NAME=com.gorite.cyclemap.test.mac scripts/device_regression.sh`
- 検証用ブロードキャスト (`SIMLOC`、`CAMERA`) の action 名は `com.gorite.cyclemap.test.*` のまま。
- 経路の作り方: 地図を長押し (540,560) → 「ナビ開始」(870,2155)。
- 横画面確認: `settings put system user_rotation 1` の前に `accelerometer_rotation 0` を設定。終わったら `user_rotation 0` と `accelerometer_rotation 1` に戻す (戻さないとアプリが横向きで起動する)。確認後は `adb shell am force-stop` で止める。
- `pm clear` は外部のデータも消すので使わない。位置情報の権限は `adb shell pm grant <pkg> android.permission.ACCESS_FINE_LOCATION`。
- 画面消灯で `adb screencap` が真っ黒になる。入力前に `dumpsys window | grep mCurrentFocus` で前面を確認する。

### レビューの回し方
- Codex: `scripts/delegate_codex.sh --readonly <指示文.md>`
- Antigravity: `scripts/delegate_agy.sh --readonly <指示文.mdのパス>` (インライン文ではなくファイルパスを渡す。長い文字列を渡すと「File name too long」になる)
- 出力は `work/review/*.out` (gitignore 済み)。指摘は鵜呑みにせず、自分で確かめてから直す。

### 注意 (Mac 固有)
- BSD sed は `-i ''` が必要で、`0,/re/` が使えない。複数行の編集は Python か Edit で行う。
- zsh では `--include=*.kt` のようなグロブが展開されて失敗するので、クォートする。
- 引用符なしの heredoc は、本文中のバッククォートのコマンドを実行する。文書は Write で書く。
