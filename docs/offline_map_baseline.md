# オフライン地図の情報量: 基準線 (Stage 0)

2026-11-08 / CycleMap α0.9.5-unified + 5県タイル(Protomaps Basemap 4.15.2, OSM 2026-11-07) / 実機 Galaxy S26 (SC-51G)

## 目的と方法
「Google Maps のような情報量にオフラインで近づける」ための、現状の差を文字で記録する。以後の各 Stage の前後で同じ地点・ズームを撮り直し、下の表の充足状況で合否を判断する。

- 比較対象: 同じ端末の Google Maps アプリを、同じ地点・同じズーム相当で個人的に参照した。**他社地図の画像・色・アイコンはリポジトリに含めない**(ここには「何がどのズームで出るか」という要素の有無だけを書く)。
- 地点(8): 広島市街(紙屋町)、宮島、山口市郊外、岡山駅、松江城、鳥取砂丘、尾道水道、大山。ズーム3段: Google z12 / z15 / z17(MapLibre では 11.5 / 14.5 / 16.5 で縮尺が揃う)。
- CycleMap 側の撮影: `scripts/capture_baseline.sh`(debug ビルドの `CameraDebugReceiver` でカメラを動かす。現在地に依存しない)。画像は `work/baseline/` に出力され、git 管理外。
- Google 側で出る渋滞色・口コミ・写真は、オンライン情報なのでオフラインの目標から除外する。

## 補足(撮影中に分かったこと)
- 2026-11-08 時点で、ベクタータイルのファイルは起動時の県に固定され県境を越えても切り替わらなかったため、現在地の県の変化に追従する処理を追加した(`VectorMapView.kt`)。

## Stage 2 進捗
### 2026-11-08 (α0.9.6-unified): 地名ラベル・国道県道の標識・鉄道
- **原因の特定:** 地名や駅名が出なかったのは、タイルのデータ不足ではなく描画側の問題だった。動的 POI ピンのレイヤーが最上段にあり、シンボルの配置優先度(上のレイヤーが先に場所を確保する)で、下にある地名ラベルを押しのけていた。
- **対応:**
  - 動的 POI ピンを `places_*`(地名)の直下に挿入し、「地名 > ピン > 道路名」の優先順にした(`VectorMapStyles.kt`)。
  - 国道(青い逆三角形)・県道(青い六角形)の標識を実行時に描いて登録し、スタイルが `network`(JP:national / JP:prefectural)で選ぶようにした(`RoadShieldImages.kt`)。高速道路は関連路線の番号が混ざるため対象外。
  - 鉄道は黒地に白い破線のゼブラ表示にした。路面電車・地下鉄は細い実線。
  - タイルの POI のうち、動的ピンが担うカテゴリ(飲食・コンビニ・トイレ・給水・バス停)はスタイルから外し、二重表示を避けた。
  - スタイルの調整は `scripts/patch_map_style.py`(冪等)が正。スタイルを作り直した後は再実行する。
- **効果(同じ地点で撮り直した比較):** 広島 z12 で「広島市」「府中町」「海田町」、z14.5 で町丁名・区名、道路上の国道番号が出る。宮島で「厳島」「宮島町」「有浦」、岡山で「岡山市」と鉄道の線路が出る。
- **残っている差:** 市街地 z12 で POI ピンが多すぎる(Stage 3)、等高線・陰影起伏(Stage 2-5)、土地利用の色の差が小さい(Stage 2-4)、ランドマーク名(Stage 3)、県道標識の実機確認(撮影時に端末がロックされ未確認)。

### 2026-11-08 (α0.9.7-unified): 土地利用・POI の出し分け・地形
- **土地利用(Stage 2-4):** 公園・森林・農地・墓地・住宅地・商業地・運動場・軍用地を別々の色で塗り分け、水域を濃くした。従来は公園・森林・墓地などが同じ色だった。色の定義は `scripts/patch_map_style.py` が正。
- **POI(Stage 3):**
  - カテゴリを14種から29種に増やした(スーパー・薬局・郵便局・銀行・学校・神社寺・宿泊・キャンプ・診療所・バス停・バー・レンタル/駐輪・充電・公共施設・スポーツ・観光案内を追加し、駅/バス停・病院/診療所を分離)。
  - 各カテゴリに出現ズーム(`minZoom`)を設けた。z11 では駅だけ、z12.5 で自転車店・病院・温泉、z14 前後で日常の店、z15.5 以上でバス停・診療所など。
  - 倍率ごとのピン数の上限を設けた(z<10.5 は0、z12 未満 25、z14 未満 110、z16 以上 220)。施設名は引くほど有名な施設だけに出す。
  - 保存済みの選択は、旧版の選択を尊重しつつ、新カテゴリのうち初期表示のものだけを足して引き継ぐ(`PoiCategory.migrateSelection`)。
- **地形(Stage 2-5):** 国土地理院の標高タイルから、等高線(10m間隔、50mごとに太線+標高ラベル)と陰影起伏を県別に生成し(`scripts/build_terrain.py`)、地図に重ねた。大山では山肌の等高線・標高ラベルと陰影が出て、緑一色だった山間部が地形図らしくなった。
- **残っている差:** 場所の詳細情報(営業時間・電話・Web、Stage 4)、ランドマークのアイコン+名称の充実(タイル由来の POI と検索DBの統合)、ライトテーマの実機確認。

### 2026-11-08 (α0.9.8-unified): アイコンの仕上げ
- **POI ピン:** 頭部を大きく(半径 10→11.5dp)、アイコンも大きく(11.5→14.5dp)し、上をわずかに明るくするグラデーション、2.4dp の白いリング、ぼかした影を付けた。
- **アイコン:** 駅(顔に見えた Lucide の train-front)を電車の側面図に、温泉を湯気つきの湯舟に、パン屋を食パン形に描き直した。
- **国道・県道の標識:** 高さ 20→25dp にし、影を付けた。国道(逆三角形)は数字を広い上寄りに置き、県道(六角形)は中央に置く。文字は 10→12。ダークの文字ハローは標識の青に溶ける濃紺(#062244)にして、数字が太く見えないようにした。
