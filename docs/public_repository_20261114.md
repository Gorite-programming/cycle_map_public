# 公開リポジトリ (2026-11-14)

公開用の `Gorite-programming/cycle_map_public` は、開発用の非公開リポジトリ (`cycle_map`) の main とタグから、次の加工をして作った履歴。

- 他社地図 (Google マップ) のスクリーンショットと、その画面ダンプを除いた
- 20 MB を超えるファイル (古い debug APK 5 点、OSM 由来の地図データ 1 点) を除いた
- 作業ログに残っていた本名入りのパス、Mac のホスト名、端末のシリアル番号を伏せ字にした
- コミットの作者のメールアドレスを GitHub の noreply アドレスにそろえた

そのほかの内容は同じ。ただし、コミットのハッシュは開発側と違う。`VERSIONS.md` や `docs/` に書かれたハッシュは開発側のものなので、下の表で読み替える。
`Archives/` の古いコードや作業ログは編集しない方針のため、公開側にも残してある (上の加工は当てている)。

## 更新の流れ

- 開発は非公開リポジトリで行う。公開側へは、開発側の `scripts/publish_public.sh --push` で反映する。加工は決まった手順なので、公開側は先頭にコミットが足されるだけで、強制 push は要らない。
- 伏せ字の対応表と、元のメールアドレスは、開発側の `scripts/publish_public_*.txt` にだけ置く (公開側には出さない)。
- 公開側に直接コミットしない。次の反映で履歴が合わなくなる。
