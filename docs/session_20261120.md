## 入ったもの

### 新機能
- **出発前のオフライン診断**: ルート確認に「オフライン準備」行。出発地・経由地・目的地が通る県ごとに、地図・検索・経路 (必須) と高速化・等高線・陰影・通り口 (任意) の有無を出す (`data/OfflineReadiness.kt`、`ui/layout/OfflineReadinessRow.kt`)。
- **目的地検索の検索範囲**: 現在地周辺 / 表示中の地図 / 導入済みの全県 (`search/DestinationSearchScope.kt`)。
- **立ち寄り検索を残りの経路に沿わせる**: ナビ中は走行済み区間を除き、「経路に沿った先までの距離 + 外れて戻る往復」の順で並べ、残りの経路が通る県の DB も引く。経路上 12km ごと最大 48km 先まで探す (`search/RemainingRouteQuickSpot.kt`)。
- **オフラインデータ画面**: 県名検索・地方フィルタ・サマリー文言 (`ui/components/OfflineDataSummary.kt`)。
- **走行の復元を走行 ID で判定する純粋ロジック** (`tracking/RideRecordingRestorePolicy.kt`)。**アプリには未接続**。設計メモは `docs/design_cycle_computer_mode.md` の追記。

- GPX の保存が終わってからサービスを止める (`GpxSaveCoordinator`)、保存開始の例外で `saving` が戻らない件。
- 代替ルート候補を選択中の好み (おすすめ/平坦/坂道) で作る、距離の基準を表示線に揃える、端点のトリムと接続線を主経路と共通化、ラスター地図の経路線の更新、立ち寄りシートの毎秒の再計算を抑える。

- POI 再検索を 50m 以上動いたときだけ、500ms ポーリングをやめる、タイル取得の writer のリーク。
