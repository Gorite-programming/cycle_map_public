# シンプルモードの設計 (2026-11-17)

検索やメニューを省き、**現在地と地図だけ**を見られる表示モード。走りながら地図を眺める、ほかの人と地図を見せ合う、といった場面で、画面の情報を最小にする。
表示モード (`DisplayMode.SIMPLE`、`ui/state/DisplayMode.kt`) は、サイコンモードの実装で土台ができている (保存・切り替えの入口)。この設計は、その上に載せる分だけ。

## 1. 決まっていること (Gorite 2026-11-16)

- 検索などを省いた、現在地と地図だけが見られる状態。
- 利き手モードは別 (ボタンの左右の入れ替え)。ただし、残すボタンは「レイヤー・3D・＋・－・現在地・ルート検索」(利き手モードの対象と同じ) をまず基準にする。

## 2. 通常画面の部品と、シンプルモードでの扱い

| 部品 | 場所 (ファイル) | シンプル |
| :--- | :--- | :--- |
| 地図本体・現在地の点 | `MapViewsContainer` | **出す** |
| 右側の操作ボタン: 現在地、＋、－、3D、レイヤー | `MapControlsOverlay` | **出す** (下の 3 章) |
| 右側の操作ボタン: エリアのダウンロード、コンパス | 同上 | 隠す (コンパスは地図を回したときだけ出す) |
| 上部: 検索欄、メニュー、カテゴリのチップ、アバター | `MapTopOverlays` | **隠す** |
| ホームの盤面 (どこへ行く?、保存済み、ルートなしで走る、今日の距離) | `MapContentLayout` (`homeVisible`) | **隠す** |
| 下部のシート (スポット / 保存済み / 記録のタブ) | `MapBottomOverlays`、`MapPanelsHost` | **隠す** |
| 天気、通信状態のバナー | `MapTopOverlays` | 隠す (電波が無いなどの警告は小さく出す) |
| 施設のピン (駅・コンビニなど) | `MapViewsContainer` | 隠す (設定で出せる。既定は隠す: 地図だけを見るため) |
| ルートの線、目的地のピン | 地図 | **出す** (ルートがあるとき) |
| 案内ヘッダ (次の曲がり角)、残り距離のバー | `MapTopOverlays` / `MapBottomOverlays` (ナビ中) | **出す** (安全のため。ナビ中に隠さない) |
| 到着カード | `MapBottomOverlays` | 出す |
| 速度の表示 | 左下の吹き出し | 出す (小さく) |

つまり、**ナビを始めていないときは地図と操作ボタンだけ**、ナビ中は案内も出す。ナビ以外の「探す」系の入口は全部隠す。

## 3. 残す操作ボタン

右側の縦の列に、次の順で出す (利き手モードのときは、列が左側になる)。
1. **現在地** (追従の入り・切り)。
2. **拡大 ＋**、**縮小 －**。
3. **3D** (2D との切り替え)。
4. **レイヤー** (標準・自転車向け・地形起伏)。
5. **ルート検索** (目的地を決める入口)。押すと、通常画面の検索画面を開き、目的地を決めたあとは、ルートプレビューからナビを始められる。ナビを始めると、シンプルモードのまま案内になる。

ボタンの大きさは通常と同じ (手袋で押せる 48dp 以上)。

## 4. モードからの出入り

- **入口**: 設定の「表示モード」に「シンプル」を足す (通常・サイコン・シンプルの 3 択)。サイコン画面の「通常モードへ戻る」と同じ並びで、シンプルの左上に小さなモード切替ボタンを置く (4 章下)。
- **出口**: 左上の小さな「モード」ボタン (アイコンだけ、半透明) を押すと、小さなメニューが開き、「通常に戻る」「サイコン」を選べる。誤操作で通常に戻っても害はないので、長押しにはしない。
- 表示モードは `cyclemap_prefs` の `display_mode` に保存される。次回の起動でも、シンプルのまま始まる。

## 5. 実装の方針

- `MapContentLayout` に `isSimpleMode: Boolean` を渡す。`true` のとき:
  - `homeVisible` を常に `false` にする。
  - `MapTopOverlays` は、ナビ中 (`isNavigationActive`) の案内ヘッダだけを出し、それ以外は描かない (`visible` の条件に `!isSimpleMode` を足す)。
  - `MapBottomOverlays` は、ルートの概要・ナビ中のパネル・到着カードだけを出し、「通常探索時」のシート (`else` の分岐) は描かない。
  - `MapControlsOverlay` は、上の 3 章のボタンだけにする (エリアのダウンロード、コンパス以外のものは `isSimpleMode` で隠す)。
  - 施設のピンは、シンプルのときは `poiVisible` を無視して隠す (設定の値は変えない)。
- 新しい `SimpleModeSwitch` (左上の小さなボタンとメニュー) を `ui/layout/` に作る。
- 状態や位置、ルート、案内は、通常と同じものを使う (モードの切り替えでルートや案内を失わない)。
- 実装は `MapContentLayout` と `MapControlsOverlay` に手を入れるため、**親 (Claude) が行う**。小さなコンポーネント (`SimpleModeSwitch`) だけは、Antigravity に任せられる。

## 6. テスト

- `DisplayMode` の保存・復元は、サイコンの実装で済み (`displayModeFromPref`)。「シンプル」を未実装として通常に戻す処理を外す。
- 表示の出し分けは、条件を純粋な関数 (`SimpleModeVisibility`: 各部品を出すかを返す) にして、単体テストする。
- 実機: 通常 → シンプル → 検索でルートを決める → ナビ開始 → 到着 → 通常に戻る、を一通り確認する。

## 7. 作る順番

1. `SimpleModeVisibility` (出し分けの純粋な関数) とテスト。
2. `MapContentLayout` / `MapTopOverlays` / `MapBottomOverlays` / `MapControlsOverlay` への `isSimpleMode` の受け渡しと、出し分け。
3. `SimpleModeSwitch` と、設定の「表示モード」にシンプルを足す。
4. 実機確認。
5. 利き手モード (ボタン列の左右入れ替え) は、このあとに作る。シンプルとサイコンの両方で効くよう、`isLeftHanded` を `DisplayModeController` と同じ流儀で配る。

## 8. 決めたこと (2026-11-17 Gorite: 既定の案)

- 施設のピンはシンプルでは隠す (選んだ場所のピンは出る)。ナビ中の案内は出す。モード切替ボタンは左上。残す操作ボタンは 3 章の 6 つだけ。
