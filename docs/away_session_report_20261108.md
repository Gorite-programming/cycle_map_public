### 読み取れること
- **平坦優先・坂道優先は、現在のデータでは基準と完全に同じ結果。** 原因は、`osm-importer` が辺に勾配(`gradePercent`)を設定しておらず、グラフ形式は勾配を持てるのに全辺で空であること(`OsmImporter.kt` の `GraphEdge(...)` 生成箇所に勾配を渡す処理が無い)。勾配を考慮する経路方針は実質的に効いていない。
- 幹線ペナルティを上げると展開ノードが約 +30〜45% 増え、経路距離は中央値で 1〜2% 短くなる。走りやすさは距離だけでは判断できない。
- 到達率は 95.5〜99.5%。到達しない組は、孤立した小さな連結成分に当たったものと推測(未検証)。
- 経路の道路種別の構成比と獲得標高は測れていない(経路結果が道路種別を持たず、勾配も無いため)。
